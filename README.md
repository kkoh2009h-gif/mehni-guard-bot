# mehni-guard-bot
Telegram group protection bot for Al-Mihni

## نظام الهمسات المجهولة

- داخل الكروب، رد على رسالة العضو المستهدف واكتب `/whisper`.
- اضغط زر **اكتب الهمسة بالخاص**، ثم اكتب نص الهمسة في محادثة البوت.
- الهمسة نصية فقط وبحد أقصى 1000 حرف، ولا يظهر اسم المرسل للمستلم.
- يجب أن يكون المستلم قد فتح البوت بالخاص وضغط Start سابقاً؛ تيليجرام لا يسمح للبوت ببدء محادثة خاصة مع مستخدم لم يبدأها.
- يمكن للمستلم الضغط على **إبلاغ للمشرفين**. البلاغ يتضمن هوية المرسل ونص الهمسة ويُرسل خاصاً إلى المشرفين الذين سبق أن فتحوا البوت.
- `/cancel` يلغي كتابة الهمسة.
- هذا النظام ليس تشفيراً من طرف إلى طرف؛ البوت يعالج نص الرسالة لتوصيلها.

بعد رفع التعديل إلى GitHub، أعد تشغيل الخدمة المستضافة حتى تحمل النسخة الجديدة من `main.py`.
